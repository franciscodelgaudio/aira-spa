# Wordmark

Logotipo do Aira Spa (PNG transparente, traço claro). Feito para fundo escuro ou sobre foto/vídeo com véu escuro, como no `Hero`. Centralizado (`mx-auto`), largura fluida `clamp(140px, 15vw, 180px)`.

Sem props. Em fundo claro (`bg-cream`, `bg-sand`) o traço claro some: use texto em `text-clay` (ex.: `AIRA SPA` em caixa alta, `tracking-[0.42em]`) em vez do logo.

```jsx
<div className="bg-ink p-12 text-center">
  <Wordmark />
</div>
```
